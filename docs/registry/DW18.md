# Developer Workshop 2018 (DW18)

The 2018 Developer Workshop split into two veins: an ESAPI scripting track (a hands-on
"ESAPI Introduction" set plus an automated MCO-planning demo and an ESAPIX library showcase)
and a heavier emphasis on the ARIA-Access / VAIS web-service and authentication stack —
OAuth/OIDC token flows, FHIR queries, SQL application roles, and the local document service.
The ESAPI samples teach plan info extraction, dose profiles, and end-to-end auto-planning;
the web-service samples are scaffolding for authenticating to and querying ARIA over its REST/
gateway APIs rather than the local scripting model.

## Standouts
- **DW18-04 (AutomatedPlanningDemo)** — end-to-end automated MCO planning with verification plans and plan-quality reporting, the highest-leverage sample here.
- **DW18-06 (AutoPlan)** — compact full auto-planning chain (PTV → MLC beams → dose calc → prescription), easy to lift as a teaching baseline.
- **DW18-01 (VAIS)** — OAuth/OIDC + FHIR authentication and query pattern for ARIA web-service access.
