# 21 Apr 2015 Webinar (W1504)

The April 2015 ESAPI webinar's worked examples, centered on radiobiological dose
equivalence (EQD2/BED) and brachytherapy. Two EQD2 plugins compute equivalent-dose-in-2Gy
for plans and plan sums (the second handling PDR brachy pulse modeling), a standalone exe
data-mines patients for brachy plans, and an RBE report plugin builds an interactive,
PDF-exportable radiobiological report posted back to ARIA. Two trivial Plugins-folder
stubs (hello/test) round out the introductory teaching material.

## Standouts
- **W1504-04 (RBEReport)** — full interactive radiobiological-effect report with editable a/b, PDF export, and ARIA document post; the highest-leverage pattern here.
- **W1504-02 (EQD2_2)** — EQD2 across plan sums with explicit PDR brachytherapy pulse-repair modeling, a genuine clinical calculation.
