# 23 Mar 2020 Webinar — ARIA Access (W2003)

The March 2020 ARIA Access webinar: a single worked console sample showing how to call the
ARIA Access web service (a REST/JSON gateway, not ESAPI) from C#. It authenticates with an
API key, posts a strongly-typed `GetMachineAppointmentsRequest`, and tallies the week's
machine appointments per patient — a template for pulling scheduling data out of ARIA over
the web-service link rather than the local scripting API.
