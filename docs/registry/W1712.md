# 17 Dec 2017 Webinar (W1712)

A single worked example from the 17 Dec 2017 webinar: a WPF binary plugin ("DoseReview")
that lets a user pick structures from the active plan and renders their cumulative DVH
curves on a canvas alongside max/min/mean dose stats, with a template-driven dose-quality-
metric model. The folder ships one ESAPI solution plus a standalone runner host used to
launch the same plugin outside Eclipse for development.
