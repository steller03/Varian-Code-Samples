# 31 Mar 2021 Webinar — Beam Data Visualization (W2103)

The March 2021 webinar shipped a single WPF MVVM standalone application (Prism + OxyPlot) that navigates to a patient/course/plan, pulls each beam's scan data — depth-dose and profile curves keyed by energy and field size — and plots them interactively, with filtering and a data-export view. It demonstrates building a polished, chartable beam-data viewer on top of ESAPI rather than a single focused API call.
