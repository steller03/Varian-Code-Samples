# 20 Aug 2020 Webinar — Constraint Export (W2008)

This webinar ships the open-source "DVH Evaluator / Plan Comparison Tool": an ESAPI binary plugin that reads a CSV constraint template (Mayo-et-al DVH analysis nomenclature), evaluates each goal against a plan or plan sum, and emits a color-coded HTML pass/fail report. It adds a multi-plan comparison mode (with a WPF plan-chooser GUI) and ships example data plus a Word template that exports patient-specific constraints from Eclipse. One Visual Studio solution with three projects — a shared main library and two thin `.esapi` entry projects (single-plan and comparison) — counted as a single unit.
