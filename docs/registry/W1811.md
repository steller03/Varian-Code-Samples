# 14 Nov 2018 Webinar — Digging Into DVH (W1811)

A single standalone-exe companion to the Nov-2018 DVH webinar, built on the ESAPIX
helper library (v15.5). It walks through DVH work end-to-end: cumulative/differential
DVHs and dose-at-volume / volume-at-dose via both native ESAPI and ESAPIX helpers,
authoring and running plan dose-constraints, multi-patient DVH "mining" to CSV, and
plotting a DVH with OxyPlot. One unit; the rest of the folder is project source.
