# Developer Workshop 2014 (DW14)

The 2014 Developer Workshop, split into a "guru track" of richer reference applications and a
set of smaller "hands-on exercises." The guru projects show production-shaped patterns — a
WPF/MVVM DICOM anonymizer with DCMTK C-MOVE retrieval, a two-plan RapidPlan dose-comparison
report, a reusable generic selection-box UI library, and an MVVM print-report demo. The
hands-on exercises are early-ESAPI teaching scripts covering DVH export, dose profiles,
data mining, scripted plan automation, and a SmartAdapt registration-accuracy (TRE) report.
This is 2014-era material (ESAPI v11 / v13.5), so it leans illustrative, but the guru track
holds several adaptable real-world patterns.

## Standouts
- **DW14-01 (ESAPIAnon)** — full C-MOVE DICOM retrieval plus profile-driven anonymization, the richest app here.
- **DW14-03 (RapidPlanEvaluation)** — two-plan standard-vs-RapidPlan comparison with DVH and biological dose metrics.
- **DW14-04 (SimpleUIDemoApp)** — reusable generic selection-box UI library, liftable into other plugins.

## Coverage
9 units catalogued, matching exactly the 9 `.sln` files present under the folder (4 guru
track projects + 5 hands-on exercises numbered 1, 2, 3, 5, 6). The 4 single-file `Plugins/*.cs`
twins were skipped as duplicates of their same-named solutions: exercise 1
`Plugins/DVHExport.cs` (twin of DVHExport.sln), exercise 3 `Plugins/DoseProfiles.cs`
(DoseProfiles.sln), exercise 5 `Plugins/Superplan.cs` (Superplan.sln), and exercise 6
`Plugins/TRE.cs` (TRE.sln). Exercise 2's `DataMining.cs` is project source inside
DataMining.sln (not a separate unit), and all guru-track `.cs` files live inside their 4
solutions. There is no exercise-4 solution or standalone script — the hands-on sequence skips
from 3 to 5, and the `dw/` folder holds only per-exercise `.snippet` text files (no unit).
