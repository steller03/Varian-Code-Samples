# 16 Jan 2020 Webinar (W2001)

A Varian-sponsored webinar by Matthew Schmidt (Washington University) teaching the MVVM
pattern for ESAPI WPF applications on Eclipse V15.6 MR3. The worked example reads calculated
DVH metrics, plots cumulative DVHs (OxyPlot), and surfaces plan dose-calculation and
prescription parameters. It ships two layouts of the same material: `AppsCombined`, where the
DVH plot, dose-metric table, and dose-parameter views are merged into one solution, and
`SeparatedApps`, where each concern is its own standalone solution — illustrating modular MVVM
composition. A root single-file launcher script shows how to start a standalone exe from
Eclipse via `Process.Start`.

## Coverage

`AppsCombined/DoseMetricExample`, and the three `SeparatedApps` solutions (`DVHPlot`,
`DoseMetrics`, `DoseParameters`), plus the root `sampleLauncher.cs`. Reconciliation: every
other `.cs` (Views/ViewModels/Models/Events/Converters/Startup/Properties and the
`.sln`-twin entry files DVHPlot.cs, DoseMetrics.cs, DoseParameters.cs) lives inside one of the
four `.csproj` projects, so none is a separate unit. `sampleLauncher.cs` sits at the folder
root with no same-named `.sln`, so it is its own unit (W2001-05). Note the deliberate overlap:
`AppsCombined` is the three apps merged into one solution while `SeparatedApps` splits the same
functionality into three solutions — all four are catalogued as distinct units per the
ground-truth list.
