# 22 Jul 2023 Developer Symposium (DS23)

The July 2023 Developer Symposium ships a single, deliberately comprehensive proton
sample: an end-to-end standalone script that builds a modulated-scanning IMPT plan from
scratch and exercises the full v18 proton API surface — course/plan creation, beam and
range-shifter setup, proton calculation-model selection, optimization objectives with a
proton NTO, robust (range/setup) uncertainty scenarios, RapidPlan DVH estimation, IMPT
optimization and dose calculation, uncertainty and delivery-dynamics calc, a DECT
verification plan, and CSV export of spot data, target mesh, and beam geometry.
