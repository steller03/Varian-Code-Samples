# Developer Workshop 2016 — katas (DW16)

The 2016 Developer Workshop "katas": a graded set of self-contained ESAPI exercises
(Newbie → Intermediate → Advanced → Proton) each shipping a worked solution. They cover the
core ESAPI surfaces a physicist automates against — DVH/dose metrics, structure operations,
beam/control-point and MLC geometry, plan QA, reporting/CSV export, database data-mining, and
a proton-specific track (spot weights, energy-layer post-processing, uncertainty DVHs). The
densest teaching vein in the repo; most units are small binary plugins or standalone exes
solving one focused problem apiece.

## Standouts
- **DW16-22 (Advanced_5)** — end-to-end automated VMAT planning (structures → beams → optimization → calc), the highest-leverage pattern here.
- **DW16-18 (DvhBioCorrection)** — linear-quadratic biological DVH correction applied across a multi-patient dataset.
- **DW16-31 (CustomPostProcessing)** — energy-dependent spot-MU limit enforcement, a real proton spot-scanning need.
