# Research Symposium 2015 (RS15)

The 2015 Research Symposium Eclipse Scripting API track ships two worked solutions aimed at research-grade automation: a full end-to-end automated planning demo (prescription dialog through optimization, dose calc, reporting, and QA verification plans) and an EUD-based TCP/NTCP calculator implementing the Gay-Niemierko method from plan DVHs. Both lean toward high-leverage, physics-oriented techniques rather than single-API teaching exercises.
