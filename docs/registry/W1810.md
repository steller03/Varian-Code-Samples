# 16 Oct 2018 Webinar (W1810)

The 16 Oct 2018 webinar demonstrated authoring custom **Visual Scripting "ActionPack" elements** —
C# components (`VisualScriptElement`) that drop into the Eclipse Visual Scripting UI as reusable
nodes, exposing user-selectable options. Two worked examples ship here: one reorders beams, one
runs configurable plan-integrity checks. Both target ESAPI / Visual Scripting 15.5 and illustrate
the element-authoring pattern (Execute method, AllowedOptions, DisplayName) rather than a
standalone tool. Small and didactic, but the second is a genuinely useful QA pattern.
