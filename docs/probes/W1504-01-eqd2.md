# W1504-01 — EQD2_1 (EQD2 per plan in scope)

**Cluster 5 delta** — exemplar [W1504-02 EQD2_2](W1504-02-eqd2-plan-sum-pdr.md).

- **Problem:** compute EQD2 (equivalent dose delivered in 2 Gy fractions) for each plan in scope and
  tabulate `plan / prescribed dose / EQD2` in a message box.
- **Differs from the exemplar:** the simpler **precursor**. It walks `context.PlansInScope`
  (individual plans), not `PlanSumsInScope`, and has **no PDR brachy** branch. Identical
  linear-quadratic math with hard-coded α/β = 10 — `BED = n·d·(1 + d/(α/β))`,
  `EQD2 = BED/(1 + 2/(α/β))` — reading `UniqueFractionation.PrescribedDosePerFraction` /
  `NumberOfFractions`. W1504-02 layers plan-sum accumulation and the Dale incomplete-repair PDR model
  on top of exactly this loop.
- **Surfaces it adds:** none beyond the exemplar (`ScriptContext.PlansInScope`,
  `PlanSetup.UniqueFractionation`, `TotalPrescribedDose`) — a strict subset.
- **Reuse note:** the LQ EQD2/BED snippet lifts directly, but W1504-02 is the strictly richer version
  (plan sums + PDR) — prefer it. Same caveats: α/β is hard-coded to 10 (make it tissue-specific) and
  the `MessageBox` should become a CSV/report sink for batch use. Verdict Liftable.
